Because this environment runs as a web server, you cannot test a browser extension directly within this preview window. You need to load it into your actual browser.

How to test it in Chrome:

  1. Download the files generated in this project.
  2. Open Chrome and navigate to chrome://extensions/
  3. Turn on Developer mode (top right).
  4. Click Load unpacked and select the downloaded folder.
  5. The setup screen will launch automatically!
